# MySQL 数据库接入（SSM）

后端采用 **SSM** 架构：

- **Spring MVC**：Controller、`/api/*`
- **Spring**：Service、配置、事务容器
- **MyBatis**：Mapper 接口 + `resources/mapper/*.xml` 访问 MySQL

表结构见项目根目录 `sql/schema.sql`，连接配置见 `online-address-book/src/main/resources/datasource.properties`。

## 准备数据库

```bash
mysql -u root -p < sql/schema.sql
```

重置测试数据：

```bash
mysql -u root -p online_address_book < sql/seed-data.sql
```

## 配置连接

编辑 `online-address-book/src/main/resources/datasource.properties`（可从 `datasource.properties.example` 复制）。

## 持久层结构

```text
Controller → Service → Repository（接口）
                          ↓
              MyBatis*Repository → Mapper 接口 → *.xml SQL
```

| 表 | Mapper | XML |
|----|--------|-----|
| student | `StudentMapper` | `mapper/StudentMapper.xml` |
| professional | `ProfessionalMapper` | `mapper/ProfessionalMapper.xml` |
| refresh_token | `RefreshTokenMapper` | `mapper/RefreshTokenMapper.xml` |
| admin_user | `AdminUserMapper` | `mapper/AdminUserMapper.xml` |

单元测试仍使用 `InMemory*` 仓储，不依赖数据库。

## 构建与运行

```bash
cd online-address-book
mvn test package
```

部署 `target/online-address-book.war` 到 Tomcat 9。

### Tomcat / IDEA 启动报 `Failed to get driver instance`

1. **必须用 Maven 打好的 WAR**（`mvn package`），或 IDEA 部署时 Artifact 类型选 **War exploded**，且 `WEB-INF/lib` 里要有 `mysql-connector-j-*.jar`。
2. `datasource.properties` 中已配置 `datasource.driver=com.mysql.cj.jdbc.Driver`。
3. 确认本机 MySQL 已启动，且已执行 `sql/schema.sql`；`datasource.password` 与本地一致。
4. 若仍失败：Tomcat 不要用「仅 exploded 模块输出、不带 Maven 依赖」的 Artifact，改复制 `target/online-address-book.war` 到 `webapps`。
