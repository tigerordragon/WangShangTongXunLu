# MySQL 数据库接入

后端已由内存仓储切换为 JDBC + MySQL，与项目根目录 `sql/schema.sql` 表结构一致。前端页面仍通过 `/api/*` 调用现有 Controller，数据来自数据库。

## 准备数据库

```bash
mysql -u root -p < sql/schema.sql
```

如需重置测试数据：

```bash
mysql -u root -p online_address_book < sql/seed-data.sql
```

## 配置连接

编辑 `online-address-book/src/main/resources/jdbc.properties`（可参考同目录 `jdbc.properties.example`）：

```properties
jdbc.url=jdbc:mysql://localhost:3306/online_address_book?...
jdbc.username=root
jdbc.password=你的密码
```

## 运行与验证

```bash
cd online-address-book
mvn clean package
```

将 `target/online-address-book.war` 部署到 Tomcat 后访问页面。示例账号（密码均为 `123456`）：

| 账号 | 状态 | 用途 |
|------|------|------|
| student | 已通过 | 登录、个人通讯录、查询同学 |
| sunqi_pending | 待审核 | 管理员审核列表 |
| qianba_disabled | 已禁用 | 不可登录 |

管理员学生审核、禁用/启用、专业维护等接口读写 `student`、`professional`、`refresh_token` 表。管理员账号登录仍使用浏览器 `localStorage`（`admin_user` 表为预留）。
