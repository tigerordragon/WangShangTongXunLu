# 学生登录与登录信息记录

负责人：B

## 功能目标

学生可以使用账号和密码登录系统。系统只允许审核通过的学生登录，并记录学生登录次数和最近登录时间。

## 后端范围

后端需要提供学生登录验证能力。登录时校验账号、密码和审核状态。

**补充：登录时还需校验账户是否被禁用（见 docs/6），被禁用的账户拒绝登录。**

登录成功后，系统更新最近登录时间，并累计登录次数。

后端需要提供学生查看自己登录记录的能力，页面可展示登录次数和最近登录时间。

## 前端范围

前端需要提供学生登录页面。

个人中心需要展示学生登录次数和最近登录时间。

## 验收结果

审核通过的学生可以登录系统。登录成功后，个人中心能看到最新登录时间和累计登录次数。
